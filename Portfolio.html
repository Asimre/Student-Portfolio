About Me

Hi, I'm Davey.

Hi, I’m Davey, an IT student with an interest in web development and user interface design. I enjoy learning how websites and applications are built, especially using HTML and CSS to turn an idea into something people can actually interact with.

What draws me to IT is the process of figuring out how things work and then using what I learn to create something of my own. I’m particularly interested in frontend development because I like working on both the visual side of a website and the way its layout affects the user’s experience.

I’m currently learning more about web development, UI/UX design, and programming languages like C# and MySQL. I’m always looking for opportunities to improve my skills and work on projects that challenge me to think creatively and solve problems.

I’m still building my skills and learning through different projects, but my goal is to continue improving as a developer and eventually work in frontend development.
